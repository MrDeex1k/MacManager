# Uchwyt GPU i powiadomienia sieciowe

Data: 2026-10-12. Branch: `feat/battery-optimization`. Bez zmiany wersji 0.8.3.

## Implementacja

- Sampler przechowuje własny uchwyt IOKit do jednego obsługiwanego AGXAccelerator. Kolejne próbki odczytują aktualne PerformanceStatistics bez ponownego przeszukiwania rejestru. Nie buforujemy wartości procentowej. Po nieudanym odczycie uchwyt jest zwalniany i urządzenie ponownie wyszukiwane. Reset samplera, wyłączenie odczytu GPU oraz zakończenie życia samplera zwalniają uchwyt. Dotychczasowe API jednorazowego odczytu pozostaje dostępne.
- SCDynamicStore obserwuje globalny IPv4/IPv6, stan interfejsów i usług oraz konfigurację sieci. Callbacki są dostarczane na main queue; pamięć kontekstu CF jest zarządzana niezależnie od MainActor, ponieważ system może zwalniać ją na wewnętrznej kolejce. Spóźnione callbacki po stop są ignorowane.
- Seria powiadomień jest scalana przez 200 ms przed odczytem. Zmiany stanu sieci unieważniają odczyt publicznego IP z dotychczasowym ograniczeniem prób. Sama zmiana konfiguracji Setup uruchamia ponowny odczyt lokalny; bez zmiany środowiska nie unieważnia publicznego IP. NWPathMonitor nadal dostarcza stan online/offline.
- Kontrola awaryjna lokalnych danych działa co 60 s, w tle w trybie oszczędzania co 300 s. Gdy rejestracja obserwatora się nie powiedzie, wracamy do odczytów co 5/30 s. Uśpienie odłącza obserwatora, wybudzenie ponownie go rejestruje i odczytuje bieżące dane. Zakończenie HTTP ponownie planuje timer, żeby rzadsza kontrola lokalna nie opóźniała ponowienia publicznego IP.

API obserwacji: [SCDynamicStoreSetNotificationKeys](https://developer.apple.com/documentation/systemconfiguration/scdynamicstoresetnotificationkeys(_:_:_:)) oraz [SCDynamicStoreSetDispatchQueue](https://developer.apple.com/documentation/systemconfiguration/scdynamicstoresetdispatchqueue(_:_:)).

## Weryfikacja

- 107 testów Core Release: PASS, z rzeczywistym fixture Spotlight.
- Finalny build Release arm64: PASS. Pozostał dotychczasowy komunikat o braku zależności AppIntents.
- Harness `scripts/test-gpu-network.swift`: rzeczywisty odczyt GPU, 12 kolejnych odczytów z identycznym uchwytem, zwolnienie i ponowne wyszukanie GPU, rejestracja/stop/ponowna rejestracja SCDynamicStore: PASS.
- Syntetyczne dostarczenie callbacku z prywatnego tymczasowego wpisu: SKIP. Zapis do dynamic store wymaga administratora; `sudo -n` nie miało dostępnego uwierzytelnienia. Harness wykonuje tę część wyłącznie z uprawnieniami root. Nie zmieniano konfiguracji sieci ani nie nadawano aplikacji nowych uprawnień.
- Fizyczna zmiana Wi-Fi/VPN, uśpienie i pomiar energii pozostają do ręcznego odbioru. Nie deklarujemy ilościowej poprawy czasu pracy na baterii.

Powtórzenie próby po buildzie do `.build/battery-release`:

```sh
swiftc -swift-version 6 -parse-as-library -target arm64-apple-macosx26.0 \
  -I .build/battery-release/Build/Products/Release \
  -Xcc -fmodule-map-file=.build/battery-release/Build/Intermediates.noindex/GeneratedModuleMaps/MMHardware.modulemap \
  scripts/test-gpu-network.swift MacManager/Platform/Network/NetworkConfigurationMonitor.swift \
  .build/battery-release/Build/Products/Release/MMHardware.o \
  -framework IOKit -framework SystemConfiguration -o /tmp/mm-gpu-network-check
/tmp/mm-gpu-network-check
```

Test GPU wymaga urządzenia udostępniającego obsługiwany licznik AGX. Nie instalowano buildu w `/Applications`, nie wypychano zmian ani nie tworzono PR.
